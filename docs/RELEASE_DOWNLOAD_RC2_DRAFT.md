# 향후 rc.2 Release 다운로드 설명 초안

**게시 전 편집용입니다. 현재 공개 rc.1 Release를 수정하거나 rc.2를 배포한 문서가 아닙니다.** 실제 배포 파일명·SHA-256·지원 환경·실기 수락 결과가 확정될 때만 자리표시자를 채우세요. 로컬 검토 ZIP을 정식 배포 ZIP이라고 게시하지 마세요.

---

Ambient Workspace는 YouTube의 분위기를 웹 배경과 Windows 주변 조명으로 연결하는 무료 오픈소스 앱입니다. 이 버전은 정식판 전 공개 테스트 RC입니다.

## Windows 다운로드: ZIP 하나만 받으세요

**Assets → `실제_확정된_Windows_설치_ZIP_파일명.zip`**을 선택하세요. GitHub가 자동으로 만드는 **Source code (zip)**은 설치 파일이 아닙니다. 별도 설치 도우미 다운로드는 필요하지 않습니다.

ZIP SHA-256 (설치 화면에 복사할 독립 게시 값):

```text
출시_검증을_마친_실제_ZIP의_64자리_SHA256으로_교체
```

1. ZIP을 **모두 압축 풀기**하고 원본 ZIP도 보관하세요.
2. 풀린 폴더의 **Install.bat** → 위 SHA-256 입력 → 출처 확인 → **확인 후 설치**.
3. **Chrome 확장 관리 열기** → 개발자 모드 → 압축해제된 확장 프로그램 로드 → **폴더 위치 복사**로 안내된 `Browser_Extension` 폴더 선택.
4. Windows 앱도 쓰면 **Desktop 실행 → 연결 등록 열기**, 직접 등록 승인 후 팝업 **Windows 연결**. Chrome만 쓰면 등록·페어링 없이 완료합니다.

[화면으로 따라 하는 안내](GETTING_STARTED.md) · [문제 해결](TROUBLESHOOTING.md)

기존 사용자는 설치 전 Desktop을 정상 종료하고 **기존 Desktop에서 업데이트 · 설정과 키 보존**을 선택합니다. 개인 파일 복사는 별도 승인 후 새 폴더에만 수행합니다. 기존 폴더·키·설정은 초기화하지 않습니다.

개인 Windows 계정·로컬 NTFS·PowerShell 5.1/WPF·지원 Chrome이 필요합니다. Chrome Web Store 미게시로 확장 추가는 직접 승인합니다. SHA-256·내부 manifest는 배포자 전자서명이 아닙니다. **미서명 패키지가 Windows/조직 정책으로 차단되면 보안을 끄거나 관리자 실행으로 우회하지 않습니다.** 게시 전 서명·실제 다운로드 시험 결과와 제한을 여기에 명시하세요.

게시 전 최종 검토: 실제 ZIP 이름·해시, 서명/정책 차단, 신규·업데이트 실기, Chrome-only·Desktop+Chrome·키 보존·Pause 회귀, 알려진 문제, MIT·제3자 고지 링크. 자동 체크섬 파일은 고급 확인용으로 추가 게시할 수 있지만 일반 사용자 필수 다운로드는 Windows ZIP 하나입니다.
