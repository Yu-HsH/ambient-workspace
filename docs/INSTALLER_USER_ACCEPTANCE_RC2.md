**잠정 평가:** 신규·업그레이드 설치, 데이터 보존, 기존 키 인증과 조명 표시는 사용자 보고로 확인했습니다. Native 등록 경로 변경 후 확장을 새로고침해야 했던 연결 문제는 후속 UX 개선 대상으로 남습니다. 일반 사용자 난이도, 흐릿한 영상 모드 전체, 장시간 안정성, 재시작·복원 절차는 아직 별도 검증이 필요합니다. 상세 버전·개인 경로·키 원문은 추정하거나 공개 기록에 추가하지 않습니다.
