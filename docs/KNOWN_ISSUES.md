# 1.0.0-rc.1 Known Issues

정식 출시 전 공개 테스트 RC입니다. 2026-10-23 소유자가 아래 잔여 위험을 RC 단계에서 수용했습니다. 과거 간헐 실패의 원인이 해결됐다고 단정하지 않습니다. 실제 새 권한 경계 위반·비밀값 유출·데이터 손실·반복 제어 실패가 확인되면 출시를 재심사합니다.

| 분류 | 항목 | 제한·대응 |
|---|---|---|
| ACCEPTED RISK | 단일 사용자 지원 | 본인 전용 Windows 계정·ACL PASS 로컬 NTFS 설치만 지원. **실제 두 Windows 계정 로그인 접근 실험은 미수행**이며 이번 RC 필수 조건에서 제외. 향후 검증 과제. 공용 계정·공유 폴더·조직 정책 환경의 안전성 보장 없음 |

문의에는 시각·오류 코드·시작/재시작 여부부터 제공합니다. 키·전체 설정·JPEG·Chrome 프로필·이전 백업·원문 로그를 보내지 않습니다. 복구는 [FAQ](FAQ.md), [설치 안내](WINDOWS_PORTABLE_GUIDE.md), [Native 등록 안내](NATIVE_MESSAGING_GUIDE.md)를 따릅니다.

2026-10-23 집중 진단에서 Chrome 재시작 후 같은 프레임 실패를 재현했습니다. 관측된 실행은 공유 Native 제어 요청의 타임아웃이 준비 확인 ping까지 취소했고, source/crop/웹 캡처는 정상이지만 해당 세션의 Windows 송신은 시작되지 않았습니다. 실제 WPF Desktop을 포함한 시험에서도 관측돼 fixture 전용 문제로 한정하지 않습니다. 최초 두 실패의 원인과 모든 간헐 실패의 원인이 같다는 증거는 없습니다. 팝업 재진입 시 이 상태와 명시 재연결 안내를 표시하도록 수정했으며, 키를 보존한 연결 해제·재연결 복구를 확인했습니다. Native 지연/공유 연결 취소 현상 자체의 영구 해결이나 실패 확률0을 의미하지 않습니다.
