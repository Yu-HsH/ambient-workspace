# 자주 묻는 질문

**어디서 다운로드하나요?** [공식 GitHub Releases](https://github.com/Yu-HsH/ambient-workspace/releases)에 게시되는 전체 Windows ZIP을 사용합니다. 현재는 사용자 수락을 반영한 로컬 RC이며 push·태그·Release 게시 전입니다. 공개 최종 승인 후 게시할 예정이므로 Release가 없다면 아직 배포되지 않은 상태입니다. [README의 다운로드·해시 확인 안내](../README.md)와 [Known Issues](KNOWN_ISSUES.md)를 확인하세요.

**관리자 권한·설치 프로그램이 필요한가요?** 압축 해제 후 Start.bat을 실행합니다. Chrome 연결을 위해 사용자별 등록을 한 번 수행합니다. Windows PowerShell 5.1/WPF·기본 .NET 컴파일러를 사용하며 Node/Python·Web Store·새 SDK가 필요하지 않습니다. 폴더를 옮기면 재등록해야 합니다.

**기존 설정·페어링이 없어지나요?** 자동 삭제·키 재발급을 하지 않습니다. Desktop 설정·키는 첫 실행 전에 새 개인 폴더에 복사합니다. 예전 key 없는 확장 ID의 설정은 [닫힌 복사본 이전 절차](NATIVE_MESSAGING_GUIDE.md)로 보존합니다. 예전 확장을 비활성화하고 원본은 남겨 두세요. 새 ID에서 자동 초기화/재페어링으로 우회하지 않습니다.

**연결이 안 되면 포트를 바꾸나요?** 새 제품은 HTTP 포트를 사용하지 않습니다. Setup-Chrome.bat → 등록 확인/재등록과 팝업의 실제 연결을 확인하세요. 등록 성공·코드 저장·실제 인증·영상 캡처는 각각 확인합니다. [오류와 복구](NATIVE_MESSAGING_GUIDE.md)를 따르고 HTTP fallback을 추가하지 마세요.

**빛이 보이지 않아요.** 트레이 실행 여부·지원 앱 활성 상태·개별 RGB/영상 ON·통합 pause를 확인하세요. 대상 앱은 고급·진단에서 봅니다. 페어링과 영상 캡처는 별개이며 YouTube 명시적 연결·Windows 전송·흐릿한 영상 전송·Desktop 영상 ON을 확인하세요.

**pause하면 화면 공유가 끝나나요?** 처리와 출력을 멈추고 세션/트랙을 유지합니다. 공유 자체는 확장 연결 중지나 source 탭 종료로 끝납니다. Desktop 종료도 Chrome 전체 캡처 종료를 대신하지 않습니다.

**다른 사이트로 이동하면요?** source가 비허용 도메인으로 이동하면 신규 처리를 차단합니다. 뒤로 돌아와도 다시 명시적으로 연결합니다. 이벤트 전 경합과 이미 보낸 데이터 회수 불가는 남습니다.

**SECURITY 때문에 실행되지 않아요.** 실제 ACL이 데이터/제품/부모 경로를 다른 계정에 열어 두었거나 검사할 수 없는 위치입니다. [원인 코드와 복사 절차](WINDOWS_PORTABLE_GUIDE.md)를 따르세요. 관리자 실행·Everyone 권한 추가·개인 파일 삭제로 우회하지 마세요.

**단축키가 작동하지 않아요.** Desktop 설정에서 켜고 저장합니다. 다른 앱과 충돌하면 실패 표시를 확인하고 다른 조합으로 재시도하세요. 잠금 화면/분리된 세션에서 입력 전달은 보장하지 않습니다. Chrome 자체 단축키와 별도입니다.

**Chrome 재시작 뒤 다시 페어링하나요?** 키·설정과 사용자 등록은 유지하지만 종료된 캡처는 다시 명시적으로 연결합니다. worker/host 종료 뒤 연결 복구와 명령 자동 재전송은 별개이며 결과 불명인 제어 명령을 자동 재실행하지 않습니다.

**어떻게 제거하나요?** Chrome·Desktop 종료 후 Setup-Chrome.bat → 등록 해제합니다. 다른 경로 등록이나 개인 파일은 삭제하지 않습니다. 확장·백업·폴더 보관/삭제는 확인 후 사용자가 결정합니다.

**로그를 보내도 되나요?** 오류 코드·시각·짧은 문구부터 전달하세요. 키·설정 전체·JPEG·프로필·이전 백업은 보내지 마세요. 로그에도 프로세스명·좌표·시각이 남을 수 있습니다.


## YouTube 연결 시작이 끝나지 않거나 JPEG가 느려요

영상과 페이지 로딩이 끝난 뒤 팝업을 다시 열어 현재 연결 상태를 확인하세요. 미연결이면 연결 버튼을 명시적으로 누릅니다. 설정 초기화·페어링 해제는 필요하지 않습니다. source 이동·레이아웃 변경 중에는 안전을 위해 연결이 취소될 수 있습니다. 반복 실패 시 실제 키·전체 설정·영상은 공유하지 말고 오류 문구와 시작/재시작 여부만 기록하세요.

Chrome 재시작 직후 Native 준비 확인이 실패하면 웹/YouTube 캡처만 연결되고 Windows 송신은 시작되지 않을 수 있습니다. 이 상태는 기다리거나 팝업을 다시 여는 것만으로 Windows 송신이 자동 복구되지 않습니다. 팝업의 **Windows 전송이 시작되지 않았어요** 안내를 확인하고, Desktop 트레이 실행·Windows 전송 ON·개별 영상 ON·통합 pause 상태를 확인한 뒤 **연결 해제 → YouTube에서 다시 연결**하세요. 기존 키·설정은 유지합니다. 계속 실패하면 Native 등록 안내의 읽기 전용 확인을 따르며 자동 재페어링·초기화·관리자 실행으로 우회하지 않습니다.

새 후보는 JPEG 변환을 내부 Worker로 분리했습니다. FPS 설정은 상한이며 실제 전송·표시 속도는 인코딩·Native 응답·PC 상태에 따라 낮아질 수 있습니다. 실험5/10FPS를 보장하지 않습니다. JPEG만 실패하면 기존 설정을 유지한 채 연결을 해제하고 상태를 확인한 후 다시 연결하세요. 공유 폴더의 SECURITY 오류는 [Portable Guide](WINDOWS_PORTABLE_GUIDE.md)를 따릅니다.
