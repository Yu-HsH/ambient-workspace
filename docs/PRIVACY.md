# 개인정보와 로컬 처리

이 안내는 단일 사용자용 `1.0.0-rc.1` RC에 적용합니다. 본인 전용 Windows 계정·ACL PASS 로컬 NTFS 설치만 지원합니다. 실제 두 일반 계정 로그인 접근 실험은 미수행이며 이번 RC 필수 조건에서 제외하고 향후 과제로 유지합니다. 공용 계정·공유 폴더·조직 정책 환경의 안전성을 보장하지 않습니다. 새 제품은 Chrome Native Messaging 표준 입출력을 사용하며 localhost HTTP 송신/리스너/fallback이 없습니다. 예전 확장을 계속 실행하면 옛 경로가 남으므로 전환 시 비활성화하고 [이전 안내](NATIVE_MESSAGING_GUIDE.md)를 따르세요.

팝업에서 명시적으로 연결한 YouTube 탭의 video stream을 받습니다. tabCapture는 탭 영상 stream을 만들고 offscreen에서 플레이어 영역을 자릅니다. 시스템 전체 화면·다른 창·오디오 캡처는 요청하지 않습니다. JPEG 변환은 확장 내부의 기본 Worker에서 처리하며 작업은 한 개로 제한합니다. Worker에는 잘라낸 bitmap과 크기·화질만 전달하고 키·URL·설정은 전달하지 않습니다. 캡처 중지 때 Worker를 해제하며 이 변경으로 runtime 디스크 파일을 추가하지 않습니다. 소스상 외부 분석·업로드·원격 코드 API는 발견하지 않았습니다. 방문 사이트·Chrome 자체 통신과 실제 전체 네트워크 패킷 감사는 별개입니다.

허용된 확장 ID만 Native host에 연결하고, 페어링 검증 전 RGB/JPEG·제어 명령은 거부합니다. 키는 표준 입출력으로만 전달하며 개인 디스크 명령 큐에서는 제거합니다. 색·선택적 저해상도 JPEG·제어 상태는 같은 사용자 프로세스와 개인 파일을 거칩니다. 디스크 암호화·동일 사용자 악성 프로세스 방어는 제공하지 않습니다. 독자적인 암호 세션 설계는 연구 기록으로만 보존합니다.

source가 비허용 사이트로 이동하면 신규 처리·송신을 막고 지연 작업을 폐기합니다. 이벤트 수신 전 경합과 이미 보낸 데이터 회수는 보장하지 않습니다. pause는 처리/송신 gate이며 stream 종료는 연결 중지입니다. Demo는 연결 없이 작동합니다.

Desktop 폴더에 설정/백업·재사용 페어링 키·control JSON·JPEG/snapshot·선택적 계측·startup/diagnostic/Bridge 로그를 저장합니다. Native host 파일/manifest·등록 복구 기록·명령 큐·확장 설정 백업·이전 준비 폴더도 같은 개인 폴더에 남습니다. Chrome 프로필에는 별도의 키 복사본과 설정이 있습니다. local 저장소는 trusted context로 제한하고 content script에는 공개 설정만 제공합니다. HKCU에는 현재 사용자 host manifest의 경로를 등록합니다. 설정·키의 LocalAppData 자동 이전·자동 재발급은 없습니다.

설정 이전은 닫힌 원본 확장 DB만 새 개인 프로필에 복사해 신뢰 가능한 도우미에서 백업합니다. 원본·준비 폴더·백업은 자동 삭제하지 않습니다. 로그인·방문 기록·쿠키를 옮기지 않습니다. 백업에는 키가 들어갈 수 있으며 원문은 팝업/보고서에 표시하지 않습니다. 복원 전 현재 설정도 백업합니다. [보존·복구 절차](NATIVE_MESSAGING_GUIDE.md)를 확인하세요.

JPEG는 고유 임시 파일로 만든 후 교체하고 보통 12~15초 뒤 정리합니다. 정상 Desktop 종료와 다음 Bridge 시작에도 자신의 frames/snapshots를 정리합니다. 잠금·부하·강제 종료·정전 시 다음 정상 시작까지 남을 수 있습니다. 암호화·보안 삭제를 보장하지 않습니다. Chrome 연결 중지만으로 즉시 사라지지는 않습니다.

진단 로그는 약 1MiB와 백업 한 개, startup은 최근 실패, Bridge는 다음 기록 시 약 1MiB 초과면 초기화합니다. 큰 기존 로그의 첫 백업은 더 클 수 있습니다. 프로세스명·좌표·시각이 남을 수 있습니다. 토큰·프레임·오류 원문 기록은 제한하지만 과거 자료까지 비밀값이 없다고 보증하지 않습니다.

코드는 명시적 복사 버튼을 누를 때만 클립보드에 복사하며 자동 제거하지 않습니다. Windows 클립보드 기록·동기화에 남을 수 있습니다. 붙여넣기 후 확인하고 공유하지 마세요. Chrome 페어링 해제는 Chrome 복사본만 제거하며 Desktop 키를 취소하지 않습니다.

실제 파일·제품·상위 경로·등록 ACL로 다른 일반 계정의 읽기/변조를 제한해야 합니다. 사용자 폴더라는 이름만으로 보장하지 않습니다. 관리자·SYSTEM·동일 사용자 악성코드·공용 계정·기존 공유 사본·동기화/개인 백업은 경계 밖입니다. 실제 두 일반 계정 로그인 시험은 미수행입니다. 개인 파일·프로필·백업을 GitHub나 문의 첨부에 포함하지 마세요.
