# Ambient Workspace 1.0.0-rc.1 — 공개 테스트 RC

정식1.0.0이 아닙니다. 지원 범위는 **본인 전용 Windows 계정·ACL 검사 PASS의 로컬 NTFS 설치**입니다. 실제 두 Windows 계정 접근 실험은 수행하지 않았으며 이번 RC 필수 조건에서 제외하고 향후 과제로 유지합니다. 공용 계정·공유 폴더·조직 정책 환경의 안전성을 보장하지 않습니다.

## 포함된 기능

- Windows Portable Start.bat·트레이·설정/페어링 보존·선택적 전역 단축키.
- Desktop/웹/YouTube 조명과 캡처 처리의 통합 Pause/Resume·개별 OFF 보존.
- source 이동 차단·늦은 프레임 폐기, trusted 저장소/privileged sender 검증, 개인 설치의 실제 ACL 사전 검사.
- Chrome Native Messaging 사용자별 등록·복구·제거, 고정 확장 ID, 기존 설정의 복사본 이전. localhost HTTP 송신/리스너/fallback 없음.
- JPEG 내부 Worker의 단일작업·크기/기한·epoch 검사. 새 제품 의존성 추가 없음.
- 새 SVG/PNG 아이콘과 자체 [MIT](../LICENSE), 별도 [제3자 고지](../THIRD_PARTY_NOTICES.md).

## 사용자 수락과 기존 회귀

2026-10-23 사용자가 현재 Native RC에 대해 직접 보고한 결과입니다.

| 확인 | 결과 |
|---|---|
| 캡처 시작·종료 |10/10 PASS|
| Chrome·Desktop 재시작 |설정·페어링 유지|
| 30분 이상 뒤 팝업 |상태 조회·Pause/Resume 정상|
| ChatGPT·Codex·Windows |영상 출력 정상|
| 개별 OFF·통합 일시정지 |정상|
| 자동 회귀 |52/52 PASS. 기존 최종 runner 기록과 일치|

기존 전체52/52는 FAIL0/SKIP0이며, 새 ZIP 검사 횟수로 합산하지 않습니다. 기존 자동 검증 환경은 Windows 커널10.0.26200.0·WinPS5.1.26100.9711·Chrome155.0.8059.85·Node24.18.0입니다. 사용자 수락의 정확한 ZIP 해시·OS/Chrome 버전·실측 FPS를 추정하지 않습니다. 모든 버전/정책 호환성 보장은 아닙니다.

공개 준비 ZIP의 새 격리 검사에서는 압축해제 원본 코드의 ACL/Native 등록·컴파일·인증 통신·등록 제거9/9, 별도 시험 사본의 Start.bat/WPF·재시작/이동5/5를 통과했습니다. 실제 사용 중인 설치를 보존하기 위해 고유 시험 host·mutex·빈 Chrome 프로필을 사용했습니다. Chrome 보안/재시작 검사는 처음 두 실행이9/10 뒤 새 프레임 확인에 실패했고, 제품·단언·기한을 유지한 후속은10/10이었습니다. 후속에 추가된 것은 실패 후 상태 읽기뿐입니다. 이 결과를 전체 PASS나 원인 해결로 합치지 않습니다. 실제 호스팅 다운로드·SmartScreen 및 기본 제품 등록을 덮어쓰는 재설치 검증은 수행하지 않았습니다.

## RC 잔여 위험

기존 간헐 캡처 시작 실패·장시간 반복 후 팝업 복귀 실패의 원인/영구 해결은 미확정입니다. 사용자 수락은 이 원인 규명이나 실패 확률0의 증거가 아닙니다. 사용자30분 이상 확인을 새60분 soak로 표시하지 않습니다.

후속 Chrome 집중 진단에서는 제어 요청 타임아웃이 같은 Native 연결의 준비 ping을 취소하여 웹 캡처만 시작되는 경로를 확인했습니다. 실제 WPF Desktop 시험에서도 관측했지만 최초 두 실패까지 같은 원인으로 확정하지 않습니다. 이 세션의 Windows 송신 중단을 팝업 재진입 후에도 알리고 [연결 해제·재연결](FAQ.md)을 안내하도록 최소 수정했습니다. Native 지연과 공유 연결 취소의 영구 해결은 아닙니다. 기존 실패 기록과 기한은 유지합니다.

기본2FPS는 상한이며 짧은 표본에서1.87~2.00 ACK/초를 관측했습니다. 실험5는2.74~2.75, 실험10은6.50~7.12 ACK/초로 설정 상한 미달이며, 실험 표시를 유지합니다. ACK는 표시 FPS가 아니며 장시간·전체 host 자원 성능 보장이 아닙니다.

SA-01 비원자적 이동 경합·이미 보낸 데이터 회수 불가, 과거 키·JPEG/백업/클립보드 잔존, 같은 사용자 악성코드·부하, 미검증 환경을 [Known Issues](KNOWN_ISSUES.md)와 [PRIVACY](PRIVACY.md)에 유지합니다. 소유자가 이 위험을 RC 단계에서 수용했습니다.

## 설치·업데이트·제거

게시 위치는 [공식 GitHub Releases](https://github.com/Yu-HsH/ambient-workspace/releases)입니다. 현재는 로컬 게시 준비 단계로 push·태그·Release 게시를 하지 않았습니다. 게시 후 Assets의 전체 `AmbientWorkspace-1.0.0-rc.1-windows.zip`과 SHA-256 확인 파일을 사용합니다. [README](../README.md)에 다운로드·파일 확인·초기 연결 순서를 정리했습니다.

[Windows 설치 안내](WINDOWS_PORTABLE_GUIDE.md)와 [Native 등록/보존/복구](NATIVE_MESSAGING_GUIDE.md)를 따릅니다. 기존 설정·키는 첫 실행 전에 안전하게 복사하고 실제 ACL을 재검사합니다. 원본·백업을 보존하며 자동 초기화/재페어링/권한 수정을 하지 않습니다.

ZIP에는 개인 설정/키/프로필/미디어/로그, 생성host, 등록/이전 백업, 내부 검증 자료·과거 이미지·Git 이력을 넣지 않습니다. BUILD-INFO는 RC 버전·전송 방식·고정 ID·파일 집합 digest를 식별하며 서명이나 호스팅 게시 승인 증명이 아닙니다.

2026-10-23 공개 저장소 최종 정리는 README·다운로드 안내·Native 복구 설명을 다듬은 문서 변경입니다. 제품 기능 코드는 변경하지 않았으며, 문서를 반영해 ZIP을 다시 구성했습니다. 기존 사용자 수락·자동 회귀·격리 검사는 위에 기록된 당시 결과이고 새 문서 ZIP의 전체 실행 재검증을 뜻하지 않습니다. 실제 호스팅 다운로드 검증은 여전히 미수행입니다.
